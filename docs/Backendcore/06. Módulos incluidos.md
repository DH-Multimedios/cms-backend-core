# 🧩 06. Módulos incluidos

## 🧠 Enfoque

El core se compone de módulos independientes que resuelven funcionalidades comunes y reutilizables, sin incluir lógica de negocio.

Cada módulo:

- encapsula su responsabilidad
    
- expone servicios claros
    
- puede ser utilizado de forma transversal
    

---
## 🗄️ Database

Responsable de la configuración y acceso a la base de datos.

Incluye:

- conexión a PostgreSQL
- configuración de TypeORM
- manejo de entidades
- soporte para migraciones

- es módulo base obligatorio
- utilizado por todos los demás módulos
---
## 🔐 Auth

Responsable de la autenticación del sistema.

Incluye:

- login
    
- validación de credenciales
    
- creación y validación de sesiones server-side
    
- guards de autenticación
    

---

## 👤 Users

Gestión base de usuarios.

Incluye:

- entidad de usuario (mínima)
    
- CRUD de usuarios
    
- relación con roles
    

No incluye:

- datos específicos de negocio
    

---

## 🛡️ Roles

Gestión de roles y permisos.

Incluye:

- CRUD de roles
    
- asignación de permisos
    
- permisos por módulo (ej: `users.read`, `products.update`)
    
- sistema de jerarquía (peso)
    
- soporte para flags de protección (`isProtected`)
    

---

## 📊 Audit

Registro de acciones del sistema.

Incluye:

- logging de acciones relevantes
    
- integración con eventos
    
- trazabilidad básica
    

---

## 🩺 Health

Monitoreo del estado del sistema.

Incluye:

- endpoint de health check
    
- verificación de servicios básicos (DB, etc.)
    

---

## 🗂️ Taxonomies

Sistema de clasificación reutilizable.

Incluye:

- entidad `Taxonomy` (name, type, description, imageId)
    
- soporte para múltiples tipos (category, tag, etc.)
    
- relaciones por módulo (ej: `post_categories`, `product_categories`)
    
- métodos configurables (ej: `includeImage`)
    
- integración con Media para resolver imágenes
    

---

## 📁 Files

Gestión de archivos genéricos.

Incluye:

- CRUD de archivos
    
- metadata
    
- abstracción de almacenamiento
    

---

## 🖼️ Media

Gestión de recursos visuales.

Incluye:

- CRUD de imágenes
    
- metadata asociada
    
- preparado para futuras extensiones
    

---

## ⚙️ Settings

Configuración persistente del sistema.

Incluye:

- almacenamiento clave/valor
    
- acceso global
    

---

## 🔔 Notifications

Sistema base de notificaciones.

Incluye:

- eventos internos (emitters)
    
- contratos de notificación
    

No incluye:

- implementación de proveedores (email, WhatsApp, etc.)
    

---

## 🧱 Common / Infraestructura

Utilidades compartidas entre módulos.

Incluye:

- paginación
    
- manejo de respuestas
    
- manejo de errores
    
- DTOs base
    
- decorators reutilizables
    
- integración con Swagger
    

---

## 🎯 Resultado esperado

Un conjunto de módulos:

- reutilizables
    
- desacoplados
    
- consistentes
    
- listos para ser utilizados en cualquier proyecto sin modificaciones del core
