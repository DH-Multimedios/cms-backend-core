

## 🧠 Enfoque

Se establece un flujo claro entre el desarrollo del core y su uso en los proyectos, evitando duplicación y manteniendo una evolución ordenada.

---

## 🧩 Separación de responsabilidades

### Core (`@dh/backend-core`)

- mantenido por el equipo
    
- contiene funcionalidades reutilizables
    
- evoluciona de forma controlada
    

---

### Proyectos cliente

- consumen el core como dependencia
    
- implementan lógica de negocio
    
- no modifican el core
    

---

## 🚀 Flujo de desarrollo

### 1. Desarrollo en proyectos

- se implementa una funcionalidad en un proyecto
    
- si es específica → queda en el proyecto
    
- si es reutilizable → se evalúa para el core
    

---

### 2. Incorporación al core

- se abstrae la funcionalidad
    
- se adapta a un enfoque genérico
    
- se integra como módulo o mejora
    
- se versiona el core
    

---

### 3. Publicación

- se publica una nueva versión del core
    
- se documentan los cambios
    

---

### 4. Actualización en proyectos

- cada proyecto decide cuándo actualizar
    
- se testea la integración
    
- se adopta la nueva versión progresivamente
    

---

## 🔁 Ciclo continuo

```id="cycle"
Proyecto → Identificación de mejora → Core → Versionado → Proyectos
```

---

## 📏 Reglas del flujo

- no desarrollar directamente en el core sin validación previa
    
- evitar incorporar lógica específica
    
- priorizar estabilidad del core
    
- mantener cambios pequeños y controlados
    

---

## ⚠️ Manejo de cambios

- cambios menores → se integran rápidamente
    
- cambios estructurales → se planifican
    
- cambios breaking → requieren nueva versión mayor
    

---

## 👥 Coordinación del equipo

- decisiones sobre el core pasan por coordinación
    
- se define qué entra y qué no
    
- se mantiene coherencia arquitectónica
    

---

## 🎯 Resultado esperado

Un flujo donde:

- el core mejora constantemente
    
- los proyectos se benefician sin esfuerzo extra
    
- el equipo trabaja con una base común
    
- se evita duplicación y desorden
