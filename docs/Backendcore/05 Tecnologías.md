## 🧠 Enfoque

Stack moderno, probado y alineado con el ecosistema actual de Node.js, priorizando estabilidad, productividad y mantenimiento a largo plazo.

---

## 🧱 Backend

- **NestJS**
    
    - Framework principal
        
    - Arquitectura modular
        
    - Inyección de dependencias
        
    - Base del core
        

---

## 🗄️ Base de datos

- **PostgreSQL**
    
    - Base de datos relacional
        
    - Soporte para relaciones complejas
        
    - Estabilidad y performance
        
- **TypeORM**
    
    - ORM principal
        
    - Integración nativa con NestJS
        
    - Manejo de entidades y migraciones
        

---

## 🔐 Autenticación

- **JWT (JSON Web Tokens)**
    
    - Manejo de sesiones stateless
        
    - Integración con guards de NestJS
        

---

## 📦 Gestión de paquetes

- **pnpm**
    
    - Instalación rápida
        
    - Mejor manejo de dependencias
        
    - Alineado con el workflow actual
        

---

## 📚 Documentación

- **Swagger (OpenAPI)**
    
    - Documentación automática de endpoints
        
    - Testing rápido de la API
        
    - Estandarización de contratos
        

---

## 🔔 Eventos internos

- **Event Emitter (NestJS)**
    
    - Comunicación entre módulos
        
    - Base para notificaciones y auditoría
        

---

## 📁 Archivos / Media

- Abstracción de storage
    
- Compatible con:
    
    - almacenamiento local
        
    - servicios externos (a futuro)
        

---

## 🧪 Testing (opcional en primera etapa)

- **Jest**
    
    - Testing unitario
        
    - Integración con NestJS
        

---

## ⚙️ Herramientas de desarrollo

- **TypeScript**
    
    - Tipado fuerte
        
    - Mejor mantenibilidad
        
- **ESLint + Prettier**
    
    - Estándar de código
        
    - Consistencia en el equipo
        

---

## 🐳 Infraestructura (alineado al equipo)

- **Podman / Docker**
    
    - Contenerización
        
    - Entornos reproducibles
        

---

## 🎯 Criterios de selección

Las tecnologías fueron elegidas por:

- compatibilidad con el stack actual del equipo
    
- madurez y comunidad
    
- integración con NestJS
    
- facilidad de mantenimiento
    

---

## 🚀 Resultado esperado

Un stack:

- consistente en todos los proyectos
    
- fácil de replicar
    
- preparado para escalar
    
- alineado con buenas prácticas modernas
