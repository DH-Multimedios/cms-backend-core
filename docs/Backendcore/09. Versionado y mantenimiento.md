
## 🧠 Enfoque

El core se gestiona como un paquete versionado de forma independiente, permitiendo evolucionar sin afectar directamente a los proyectos que lo utilizan.

---

## 📦 Versionado

El core sigue versionado semántico:

- **PATCH** (1.0.1)
    
    - correcciones internas
        
    - mejoras sin impacto
        
- **MINOR** (1.1.0)
    
    - nuevas funcionalidades compatibles
        
    - no requiere cambios en proyectos
        
- **MAJOR** (2.0.0)
    
    - cambios que rompen compatibilidad
        
    - requiere adaptación en proyectos
        

---

## 🔄 Actualización en proyectos

Cada proyecto:

- define la versión del core que utiliza
    
- decide cuándo actualizar
    
- puede mantenerse en versiones anteriores sin impacto
    

👉 evita rompimientos inesperados

---

## 🧩 Estrategia de compatibilidad

- mantener compatibilidad hacia atrás en cambios menores
    
- evitar breaking changes innecesarios
    
- introducir cambios grandes mediante nuevas versiones mayores
    

---

## 🛠️ Mantenimiento del core

El core evoluciona mediante:

- mejoras reutilizables
    
- corrección de errores
    
- incorporación de nuevas funcionalidades comunes
    

---

## 📏 Criterio para cambios

Antes de modificar el core:

- si es reutilizable → se incorpora al core
    
- si es específico → se resuelve en el proyecto
    

---

## ⚠️ Control de cambios

- los cambios deben ser evaluados antes de incorporarse
    
- evitar introducir lógica de negocio
    
- mantener estabilidad del core como prioridad
    

---

## 🔐 Responsabilidad

- el core es mantenido por el equipo central
    
- los proyectos consumen el core como dependencia
    

---

## 🚫 Restricciones

- no modificar el core desde proyectos cliente
    
- no depender de cambios no versionados
    
- no romper compatibilidad sin cambio de versión mayor
    

---

## 🎯 Resultado esperado

Un sistema donde:

- el core puede evolucionar de forma controlada
    
- los proyectos no se ven afectados automáticamente
    
- el equipo mantiene una base estable y confiable
    
- las actualizaciones son predecibles y seguras
