## 🧠 Enfoque

El core se utiliza como un paquete reutilizable que provee una base completa para construir APIs, evitando repetir configuraciones y funcionalidades comunes.

---

## 📦 Distribución del core

- `@dh/backend-core` se mantiene en un repositorio independiente
    
- Se distribuye como **paquete npm privado**
    
- Se instala como dependencia en cada proyecto
    

👉 No se copia código  
👉 No se utiliza como base de repositorios

---

## 🚀 Flujo para un nuevo proyecto

1. Crear proyecto NestJS
    
2. Instalar el core
    
3. Configurar el core
    
4. Agregar módulos de negocio propios
    

---

## ⚙️ Inicialización

El core se inicializa mediante configuración centralizada:

- conexión a base de datos (PostgreSQL)
    
- parámetros de autenticación
    
- configuración general
    

Ejemplo conceptual:

```id="init"
CoreModule.register({
  database: { ... },
  auth: { ... }
})
```

---

## 🗄️ Base de datos

El core incluye:

- configuración de PostgreSQL
    
- integración con TypeORM
    
- entidades base (users, roles, etc.)
    

### Migraciones

- el core provee migraciones base
    
- cada proyecto define sus propias migraciones
    

---

## 🧩 Uso en proyectos

Los proyectos:

- utilizan módulos del core (Auth, Users, Roles, etc.)
    
- agregan módulos propios (ej: Products, Posts)
    
- combinan funcionalidades sin modificar el core
    

---

## 📏 Regla de separación

- Core → funcionalidades reutilizables
    
- Proyecto → lógica de negocio
    

---

## 🔄 Evolución

Cuando aparece una nueva necesidad:

- si es reutilizable → se incorpora al core
    
- si es específica → se implementa en el proyecto
    

---

## 🚫 Restricciones

- no modificar el core desde el proyecto
    
- no duplicar funcionalidades del core
    
- no introducir lógica de negocio en el core
    

---

## 🎯 Resultado esperado

Un flujo de trabajo donde:

- los proyectos se crean rápidamente
    
- la base técnica ya está resuelta
    
- el equipo trabaja sobre una arquitectura común
    
- el mantenimiento se simplifica significativamente
